# StudySphere

A Python-based student productivity and study management application designed to help students organize and manage their academic activities in one place.

## Features

- User registration and login
- Attendance tracking
- To-do list management
- Notes management
- CGPA/GPA calculator
- Habit tracking
- Study planning
- Student profile management
- Academic progress tracking

## Technologies Used

- Python
- Lists and Dictionaries
- Conditional Statements
- Loops
- Functions
- User Input and Validation

## How to Run

1. Install Python on your computer.
2. Clone this repository.
3. Open the project folder in VS Code or any Python-compatible IDE.
4. Run the following command:

```bash
python studysphere1.py
